🛠️ Tool Integration (Claude Code & Others)

Connect any developer tool supporting OpenAI or Anthropic endpoints using your OmniRoute key.

Base URL: http://localhost:20128/v1
API Key: OR-xyz123...
Model: combo/economico

Claude Code Shortcut Script (Windows PowerShell / .cmd)

@echo off
set OMNIROUTE_API_KEY=YOUR_OMNIROUTE_KEY
set ANTHROPIC_BASE_URL=http://localhost:20128
set ANTHROPIC_API_KEY=%OMNIROUTE_API_KEY%
claude %*

Linux/macOS Bash Script

#!/bin/bash
OMNIROUTE_API_KEY="YOUR_OMNIROUTE_KEY"
ANTHROPIC_BASE_URL="http://localhost:20128"
ANTHROPIC_API_KEY="$OMNIROUTE_API_KEY"
claude "$@"
