Conectar OmniRoute

Gateway de IA local. Token mantido estritamente em memória volátil da sessão.

Endereço HTTP do daemon OmniRoute local.
Armazenado somente em memória JS (nunca em disco/localStorage).
Como criar o token no OmniRoute
  1. Abra a interface web do OmniRoute em seu navegador.
  2. Acesse o menu lateral → Settings → Access token.
  3. Clique em Create token com o nome Easy-o-Route.
  4. Selecione a permissão: Administration – Manage.
  5. Copie o token gerado (ele é exibido apenas uma vez) e cole no campo acima.

Adicionar Provedor ao OmniRoute

O Easy-O-Route prioriza provedores gratuitos. A inclusão é configurada diretamente no daemon.

Para manter sua topologia atualizada com provedores gratuitos primeiro (ex.: Gemini Flash Free, Groq, Mistral Free, Together Free) seguidos de provedores de fallback pagos:

# Via CLI do Easy-o-Route:
easy-o-route provider add --name "Groq-Free" --type "openai-compatible" --base-url "https://api.groq.com/openai/v1"

# Ou configure pelo menu do OmniRoute → Providers → Add Provider

Assim que o provedor for adicionado ao daemon, a topologia desta página refletirá automaticamente o nó no próximo ciclo de sincronização (4s).
